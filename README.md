# GO TO BI — сайт на GitHub Pages

Клон сайту gotobiplatform.com (раніше на Wix), зверстаний як статичний HTML для безкоштовного хостингу.

## Що зроблено
- `index.html` — головна сторінка (хіро, три картки курсів, про автора, деталі курсів з цінами, блог-прев'ю, відгуки, контакт, футер)
- `blog/` — три сторінки-заглушки під блог-пости (Місія Катерини, В чому моя цінність, Мій шлях до успіху) — текст треба вставити вручну, див. нижче
- `CNAME` — файл для підключення власного домену gotobiplatform.com

## Що треба доробити тобі

### 1. Фото
У коді є місця-заглушки (сірі блоки з підписом "місце для фото"):
- Hero-фото на головній
- Портретне фото в блоці "Про автора"
- Фото для трьох прев'ю блог-постів

Зайди в Wix → Media Manager, скачай оригінали собі на комп'ютер, поклади в папку `images/` у цьому репозиторії з назвами `hero-image.jpg`, `about-photo.jpg` і т.д., і онови в `index.html` рядки з `<div class="placeholder-note">` на звичайний `<img src="images/....jpg" alt="...">`.

### 2. Текст блог-постів
Три статті в `blog/` зараз — заглушки. Зайди в Wix-редактор блогу, скопіюй повний текст кожного поста і встав замість блоку з поясненням у відповідному HTML-файлі.

### 3. Публікація на GitHub Pages
1. Створи репозиторій (наприклад `kateryna-shevtsova1.github.io` — тоді сайт одразу буде на корені без підпапки в адресі)
2. Залий усі файли з цієї папки в репозиторій
3. Settings → Pages → Source → гілка `main`, папка `/ (root)` → Save
4. Через кілька хвилин сайт буде доступний на `https://<твій-акаунт>.github.io`

### 4. Підключення домену gotobiplatform.com
Файл `CNAME` вже в репозиторії з текстом `gotobiplatform.com` — цього достатньо на боці GitHub.
Далі треба зайти в DNS-налаштування самого домену (де б він не був зареєстрований — перевір у Wix → Domains, чи це Wix-домен, чи зовнішній) і прописати:

**A-записи (на @ / кореневий домен):**
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**CNAME-запис (на www):**
```
www → <твій-акаунт>.github.io
```

Після цього в Settings → Pages на GitHub впиши `gotobiplatform.com` як Custom domain і зачекай на верифікацію (може зайняти до 24 годин).

⚠️ Поки Wix-підписка активна — не вимикай хостинг, доки DNS не переключиться і новий сайт не запрацює, щоб уникнути простою.
